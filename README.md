# 个人工作台 · Daily Workbench

任务管理、计时器、复盘分析、英语学习、韩语对话、健身打卡等一体化 PWA 应用。

## 在线访问

**网页地址:** https://Gloria071708.github.io/daily-workbench/

## 安装为手机 APP

1. 在手机浏览器(Chrome/Safari)中打开上面的链接
2. 浏览器菜单 → "添加到主屏幕"
3. 即可作为独立 APP 使用,支持离线访问

## 功能

- 📝 今日任务管理
- ⏱️ 计时器(正计时/倒计时/番茄钟)
- 📅 日期倒计时
- 📊 复盘分析(AI 自动总结)
- 🇬🇧 英语学习(字幕/闪卡/口语)
- 🇰🇷 韩语对话练习
- 🏋️ 健身打卡
- 📰 每日新闻播客

## 数据存储

所有数据通过 localStorage 保存在你的设备本地,不会上传到服务器。
