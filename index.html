英语学习 · 使用说明

1. 获取字幕
在 YouTube/Bilibili 视频页面打开字幕,复制字幕文本;或下载 .srt/.vtt 字幕文件。
2. 导入字幕
选择「粘贴字幕」直接粘贴,或「上传字幕文件」选择 .srt/.vtt/.txt 文件。
3. 自动翻译
点击「加载并逐句翻译」,系统调用免费翻译 API 将每句英文翻译为中文,逐句对照显示。
4. 收藏生词
点击字幕中任意英文单词,即可加入生词本;在生词本中可查看释义与出处句子。
5. 搜索回顾
用搜索框快速定位字幕内容。

翻译由 MyMemory 免费 API 提供,每日有额度限制,如遇翻译失败请稍后再试。
